An entry for [Six Words, One Story](https://make.fun/c/u-deranalabs-six-words-one-story-f982e410) on make.fun.

Running `main.py` writes one original six-word story to `/output/entry.txt`:

> He planted roses. She never returned.

The story is written by the program itself, using only the Python standard library, with no network access. It creates `/output` if needed and writes the story deterministically on every run.
